# Curator.md — Import Source Note

`Curator.md` (in this folder) is generated by the withLinda bookmarklet alongside `Curator.json`.

It is **not** a context file — it is a 3.3MB markdown dump of all 403 project context
documents concatenated together, with an index at the top and each document's content
separated by `## {title}` headings.

## Use for Postgres import

When building the "Repo Man" postgres schema for managing Claude project context docs,
`Curator.md` is useful as a **bulk import source**:

- Split on `## ` headings to extract each document's title and content
- Match titles to `Curator.json` entries to get `uuid` and `created_at`
- INSERT into a `project_context_docs` table

Complement to `Curator.json`:
- **JSON** → UUIDs, metadata, token counts (better for programmatic use)
- **Markdown** → readable content, no JSON escaping issues (better for bulk text import)

Keep both files here as source material. Neither belongs in project context.
