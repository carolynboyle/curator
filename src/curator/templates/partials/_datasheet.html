{# _datasheet.html Reusable Tabulator child-datasheet grid. Always used as a child of _datasheet_with_header.html (which provides the + Add button, search, and controls). Renders a mount point div and a small module script that imports initDatasheet() from datasheet.js — same pattern as _tab_identities.html → bidirectional-filter.js. The full Tabulator init, save, delete, and Escape-key logic lives in datasheet.js, not here. This file's only job is passing Jinja-rendered config values (which only exist at template-render time) into a call to that module. Parameters: - container_id (str) — DOM id for Tabulator to mount to (required) - entity (str) — QueryLoader entity name (e.g. "tasks") - query_name (str) — QueryLoader query name (e.g. "for_project") - query_params (str) — Comma-separated bind parameters (e.g. "123") - columns (list) — Tabulator column definitions - parent_field (str) — Explicit FK column name for new-row inserts (e.g. "project_id" for tasks, "contact_id" for contact_emails). Never guessed from entity name. Pass '' if this datasheet has no parent. #}
